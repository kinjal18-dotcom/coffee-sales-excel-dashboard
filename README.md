# Coffee Sales Dashboard : Excel

An interactive sales dashboard built in Excel, analyzing 1,000+ coffee orders across customers, products, and countries using PivotTables, PivotCharts, and slicers.

📊 Overview

This project transforms three raw data tables (orders, customers, products) into a single-page interactive dashboard that lets a user filter total sales by year, month, coffee type, and roast type, and instantly see the top 5 customers and top sales countries.

Business questions answered:

1. How do sales trend month over month, and which coffee types drive them?

2. Who are the top 5 customers by revenue?

3. Which countries generate the most sales?
   

🛠️ Tools & Skills
1. Microsoft Excel

2. PivotTables & PivotCharts

3. Slicers (interactive filtering)

4. VLOOKUP / data joins across related tables

5. Data cleaning and relational data modeling (orders ↔ customers ↔ products)

6. Dashboard design (single-page, filter-driven layout)


📁 Files in this repo: 

coffeeOrdersProject.xlsx: Final dashboard file - PivotTables, charts, and interactive filters

coffeeOrdersData.xlsx:	Raw source data (orders, customers, products) before analysis

📈 Key Insights

1. The United States accounts for the large majority of total sales, well ahead of Ireland and the UK.

2. Sales are spread fairly evenly across the four coffee types (Arabica, Excelsa, Liberica, Robusta), with month-to-month variation.

3. The top 5 customers by revenue each contributed roughly $278–$317 in sales.

   
🔍 How it was built

* Imported and cleaned raw order, customer, and product data.

* Built relationships between the three tables to bring product pricing and customer details into the orders table.

* Created PivotTables to summarize sales by month, coffee type, customer, and country.

* Built PivotCharts and slicers on top of the PivotTables for interactive filtering.

* Assembled everything into a single Dashboard sheet.
